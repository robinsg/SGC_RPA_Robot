# Project Brief: 5250 RPA Robot

This project is a robust, YAML-driven automation framework designed to interact with IBM i systems via TN5250 terminals. It enables users to automate complex terminal tasks without writing code, bridging legacy green-screen environments with modern automation capabilities.

**Core Purpose:** To provide a reliable and flexible solution for automating repetitive tasks on IBM i systems, ensuring consistency and reducing manual effort.

**Key Technologies:**

- **Python 3.12+**: The core RPA engine.
- **tmux**: Manages persistent terminal sessions for reliability.
- **tn5250**: The standard C-based telnet 5250 emulator for IBM i connectivity.
- **YAML**: Defines automation workflows in a human-readable and structured format.
